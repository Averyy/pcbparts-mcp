# PCB Assembly Technical Capabilities

| Features | Economic PCBA | Standard PCBA |
| --- | --- | --- |
| Assembly Types | Single sided placement (SMT/Thru-hole) | Single & double sided placement (SMT/Thru-hole) |
| PCB Layer | 2,4,6-layers | 1 - 32 layers |
| Thickness | 0.8mm - 1.6mm | No limit |
| Dimension | Single PCB 10x10mm - 470x500mm; Panel 10x10mm - 250x250mm | Single PCB 70x70mm - 460x500mm; Panel 70x70mm - 250x250mm |
| Order Volume | 2 - 50 pcs | 2 - 80000 pcs |
| Delivery Format | Single PCB, Panel with mouse bites | Single PCB, Panel with mouse bites, Panel with V-cut |
| Layer Stackup | Standard stack-up only | All stack-up |
| Gold Fingers/Castellated Holes/Edge Plating | Not Support | Support |
| Edge Rails | Not necessary | Necessary |
| Fiducials | Not necessary | Necessary |
| Minimum Package | 0402 | 01005 |
| Minimum IC Pin Spacing | 0.4mm | 0.35mm |
| Minimum BGA Spacing | 0.5mm (center to center) | 0.3mm (center to center) |
| Reflow temperature | 255+/-5 C (not adjustable) | 240+/-5 C |
| SPI | No | Yes |
| AOI | Yes | Yes |
| X-ray Inspection | Yes (only for certain parts, such as BGA) | Yes (only for certain parts, such as BGA) |
| Build time | 1 - 3 days | >= 4 days |

FAQ: "For panelized PCBs, larger panels are more susceptible to bending and deformation during SMT processing. Therefore, we recommend keeping panel dimensions within 250 x 250 mm whenever possible." SMD components are reflow soldered and THT components wave soldered; THT assembly is available under both Economic and Standard PCBA.
